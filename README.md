# Dashboard Financeiro e Comercial (2018)

## Descrição do Projeto

Este projeto consiste no desenvolvimento de um dashboard interativo em Power BI para análise financeira e comercial de uma empresa no ano de 2018.

O dashboard permite acompanhar os principais indicadores de desempenho financeiro, analisar a rentabilidade dos produtos, avaliar o desempenho dos supervisores e identificar tendências de faturamento ao longo do ano.

## Objetivo

Transformar dados financeiros e comerciais em informações estratégicas, facilitando a análise de receitas, custos, lucros e desempenho das equipas comerciais.

## Ferramentas Utilizadas

- Power BI
- Power Query

## Indicadores Analisados

- Receita total;
- Custo total;
- Lucro total;
- Total de produtos vendidos;
- Margem percentual;
- Produto com maior faturamento.

## Análises Disponíveis

- Top 10 produtos mais vendidos;
- Quantidade de vendas por tipo de produto;
- Custo total por supervisor;
- Faturamento por supervisor;
- Soma do preço total por vendedor;
- Faturamento mensal.

## Funcionalidades do Dashboard

- Visualização de indicadores financeiros (KPIs);
- Análise do desempenho dos produtos;
- Comparação de resultados entre supervisores;
- Acompanhamento do faturamento mensal;
- Exploração interativa dos dados através de filtros.

## Competências Demonstradas

- Limpeza e transformação de dados com Power Query;
- Desenvolvimento de dashboards interativos em Power BI;
- Análise financeira e comercial;
- Criação e interpretação de KPIs;
